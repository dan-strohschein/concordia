Small sample projects used by tests and docs.

- `m0-sandbox`, `m1-physics-stack`, `m2-lamplight`, `m2-scripting`: the M0–M2 samples.
- `m4-canyon`: the M4 gate's canyon (4.4c), about 22 M source triangles of generated rock. Its `.glb` files aren't in git; `gen.restore` (or `just canyon-build`) makes them from the sidecars' recipes.
