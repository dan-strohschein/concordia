# ADR-0006: Licensing, clean room, DCO
- Status: Accepted
- Date: 2026-11-17

## Decision
Dual-licensed MIT OR Apache-2.0. Contributions require DCO sign-off. All code follows `docs/clean-room.md`. Dependencies must be permissively licensed; `cargo-deny` enforces this in CI. Governance moves to a foundation once there are outside maintainers.
