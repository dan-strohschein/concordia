# concordia-graph

Gameplay graphs as text: an event graph, a function, a behavior tree or a set of utility considerations is a `.graph.ron` file of nodes and links that agents and people edit, diff and review like code. This crate reads and writes the format, lists the nodes the engine offers, and checks graphs with errors that point at the node and pin to fix.

See `AGENTS.md` for invariants, tests and references.
