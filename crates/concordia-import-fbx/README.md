# concordia-import-fbx

The FBX importer: meshes, materials, textures, the node hierarchy as a prefab, skins and animation stacks, read through `ufbx-sys` and written in the same asset types and sub-asset paths as `concordia-import-gltf`. Units and axes are normalized to the engine's meters, Y-up, right-handed.

See `AGENTS.md` for invariants, tests and references.
