# concordia-terra-sim

Terra's templates, traits and spawners (ADR-0070): Mass-style traits written in Rust and configured from text, `.template.ron` files that compose them with component values, and spawners that place seeded crowds when play starts. The built-in `Lod` trait gives a template's entities a shared simulation LOD profile (ADR-0076). Built on `concordia-terra` (ADR-0069) and `concordia-scene`'s canonical RON.

See `AGENTS.md` for invariants, tests and references.
