# concordia-nav

Concordia's navigation: tiled navmeshes built with Recast from the static colliders inside a `NavMeshVolume`, with blocked and costly ground marked by `NavArea` boxes and `NavAreaGrid` cell grids; Detour queries (nearest point, paths, partial paths to the closest reachable point, surface raycasts); a DDC cache keyed by the level's input; the `nav.build` and `nav.path` methods (MCP `nav_build`, `nav_path`); the `navmesh` debug layer for screenshots; and agents (`NavAgent`) that walk character controllers along paths, replan when their target moves or they're pushed off, raise `NavArrived` and `NavPathFailed`, and show their routes in the `nav_paths` debug layer; and click-to-move (`ClickToMove`), which turns a click's pointer ray into a target through a physics raycast and a snap onto the navmesh. Enabled per project by `[nav]` in `concordia.toml` (`plans_per_tick` bounds path plans per tick); Agent Studio's level designer builds navmeshes and its gameplay programmer walks characters.

See `AGENTS.md` for invariants, tests and references.
