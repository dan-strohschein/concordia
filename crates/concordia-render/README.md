# concordia-render

Concordia's renderer: a render graph with automatic barriers and transient aliasing, clustered forward shading of Substrate-style materials, cascaded shadows, image-based lighting, GPU skinning of posed characters, view modes, gizmos, headless capture and `capture.screenshot` (optionally with the posed skeletons drawn on top).

See `AGENTS.md` for invariants, tests, performance notes and references.
