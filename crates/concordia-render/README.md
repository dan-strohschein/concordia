# concordia-render

Concordia's renderer: a render graph with automatic barriers and transient aliasing, clustered forward shading of Substrate-style materials, cascaded shadows, image-based lighting, GPU skinning of posed characters, representation LOD (far entities drawn as a cheaper mesh or not at all, chosen per camera), view modes, gizmos, debug layers from engine modules (such as the navmesh), headless capture and `capture.screenshot` (optionally with the posed skeletons or debug layers drawn on top).

Static meshes with meshlets (ADR-0100) are drawn into the same forward pass with the same materials: through object and mesh shaders where the device has them (M4 4.3b), else through a compute pass and indirect draws (4.3a); `[render] meshlets = false` turns both off. On both, the GPU culls what can't be seen before drawing (M4 4.4): whole instances and single meshlets outside the camera's view or a shadow cascade's, and meshlets whose triangles all face away; and, in two passes around a depth pyramid built from what was visible last frame, meshlets hidden behind nearer surfaces (4.4b; the `occlusion` and `hzb` views show it). `[render] culling = false` turns that off. Every path writes motion vectors (M4 4.3b2) for temporal anti-aliasing, and the `motion` view shows them.

With `[render] temporal = "own"` (M4 4.6) the camera jitters by a sub-pixel each frame and a temporal resolve gathers the frames into an anti-aliased image, optionally rendering at a lower internal size and upscaling (`[render] upscale` 1.5 or 2.0). On Apple GPUs `temporal = "metalfx"` uses Apple's MetalFX scaler instead (elsewhere it falls back to the engine's own). `render.set_temporal` changes it for a session.

With `[render] shadows = "vsm"` (M4 4.7) the sun's shadows come from virtual shadow maps instead of cascades: a clipmap of 16 huge virtual shadow maps around the camera, cut into 128-texel pages, of which only the pages some visible pixel needs are drawn, into a pool of physical pages (`[render.vsm]` sizes it). Shadows stay sharp near the camera, including thin casters. Devices without fragment atomics or 16 384-pixel attachment-less passes draw cascades instead, and `render.stats` `shadows` says which ran and why. `render.set_shadows` changes it for a session; the `shadow_mask`, `vsm_pages`, `vsm_levels` and `vsm_cache` views show the sun's visibility and the pages. Pages of still scenery are kept across frames (4.7b) and only redrawn when something under them changes; moving things draw into a per-frame copy, so a still scene costs almost nothing. `MeshRenderer.mobility` (`Auto`, `Static`, `Movable`) can hint which meshes move; a wrong hint only costs time, never changes the picture. `[render.vsm] cache = false` turns the cache off. Spot and point lights can cast shadows too (4.7c): give them `shadows` (bias and filter), and the 64 most important in view get virtual shadow maps of their own (one per spot light, six per point light) from the same page pool; spell lights stay unshadowed unless they opt in.
